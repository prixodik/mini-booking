# Spec Delta

## ADDED Requirements

### Requirement: Request timeout
Каждый запрос к API MUST прерываться, если ответ не получен за 15 секунд. Прерванный по таймауту запрос SHALL обрабатываться как сбой сети: показывается сообщение «Сервер не ответил вовремя. Повторите попытку.» и доступно действие «Повторить»; индикатор загрузки снимается, кнопки снова доступны. После таймаута создания или отмены брони список слотов MUST тихо перезагружаться, потому что запрос мог выполниться на сервере.

#### Scenario: Сервер не отвечает при загрузке
- **WHEN** `GET /api/slots` не получает ответа 15 секунд
- **THEN** спиннер загрузки пропадает, видно сообщение о таймауте и кнопка «Повторить»

#### Scenario: Сервер не отвечает при брони
- **WHEN** `POST /api/bookings` не получает ответа 15 секунд
- **THEN** диалог остаётся открытым с сообщением о таймауте и кнопкой «Повторить», кнопки снова активны, список слотов перезагружен

#### Scenario: Бронь создалась, но ответ не дошёл
- **WHEN** после таймаута брони перезагрузка списка показывает, что слот уже «Занят»
- **THEN** пользователь видит актуальный статус; повтор брони получает 409 с сообщением «Этот слот уже занят.», и список обновляется
