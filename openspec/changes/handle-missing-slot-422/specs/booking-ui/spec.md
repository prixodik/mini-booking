# Spec Delta

## MODIFIED Requirements

### Requirement: Validation errors (422)
При ответе 422 с ошибками полей формы (`customer_name`, `customer_email`) страница SHALL показать ошибки из `errors` под соответствующими полями формы, оставить форму открытой и сохранить введённые данные. Если в ответе 422 есть ошибка `errors.slot_id` (выбранного слота больше нет), страница MUST обработать её как конфликт: закрыть форму, показать сообщение сервера и обновить список слотов; действие «Повторить» в форме для этого случая MUST NOT предлагаться.

#### Scenario: Ошибка email с сервера
- **WHEN** сервер вернул 422 с `errors.customer_email`
- **THEN** сообщение отображается под полем Email, форма открыта, кнопка отправки называется «Забронировать»

#### Scenario: Слот больше не существует
- **WHEN** сервер вернул 422 с `errors.slot_id` «Выбранный слот не существует.»
- **THEN** форма закрывается, сообщение видно в уведомлении, список слотов перезагружен
