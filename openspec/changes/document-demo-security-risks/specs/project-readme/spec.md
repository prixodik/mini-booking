# Spec Delta

## ADDED Requirements

### Requirement: Demo security risks documented
README SHALL в разделе допущений перечислять известные риски безопасности демо и способ их устранения в реальном проекте: отмена любой брони по последовательному `booking_id` из публичного списка слотов (в реальном проекте — секретный токен отмены или UUID и авторизация) и отсутствие ограничения частоты `POST /api/bookings` (в реальном проекте — middleware `throttle`).

#### Scenario: Проверяющий ищет риски
- **WHEN** проверяющий читает раздел «Допущения и что не сделано»
- **THEN** он видит оба риска, ссылку на пункт ТЗ, который разрешает отмену без авторизации, и способ устранения каждого
