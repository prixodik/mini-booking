# Spec Delta

## ADDED Requirements

### Requirement: Booking dialog stays open while submitting
Пока выполняется запрос создания брони, диалог брони MUST NOT закрываться ни кнопкой закрытия, ни кнопкой «Отмена», ни клавишей Esc. После ответа сервера диалог SHALL снова закрываться всеми этими способами.

#### Scenario: Esc во время отправки
- **WHEN** пользователь нажал «Забронировать» и до ответа сервера нажимает Esc
- **THEN** диалог остаётся открытым; если сервер ответил 422, ошибки видны под полями

#### Scenario: Esc после ответа
- **WHEN** запрос завершился ошибкой (422 или сбой сети) и пользователь нажимает Esc
- **THEN** диалог закрывается
