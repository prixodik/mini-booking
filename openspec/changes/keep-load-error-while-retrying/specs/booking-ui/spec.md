# Spec Delta

## ADDED Requirements

### Requirement: Load error stays visible while retrying
Сообщение об ошибке загрузки списка с кнопкой «Повторить» SHALL оставаться на экране, пока выполняется повторный запрос; кнопка «Повторить» MUST показывать индикатор загрузки и быть неактивной до ответа. Сообщение MUST исчезать только после успешной загрузки, а при новой ошибке — заменяться текстом новой ошибки.

#### Scenario: Повтор при уже загруженном списке
- **WHEN** список слотов на экране, загрузка завершилась ошибкой и пользователь нажимает «Повторить»
- **THEN** до ответа сервера сообщение видно, на кнопке «Повторить» спиннер; после успешного ответа сообщение исчезает

#### Scenario: Повтор снова неудачен
- **WHEN** повторная загрузка тоже завершилась ошибкой
- **THEN** сообщение остаётся с текстом новой ошибки, кнопка «Повторить» снова активна
