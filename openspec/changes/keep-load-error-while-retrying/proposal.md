# Proposal

## Why

Найдено при проверке правок ревью (17.11.2026): если список слотов уже на экране, а очередная загрузка не удалась, страница
показывает сообщение об ошибке с кнопкой «Повторить». После нажатия `useBookingSlots.load()` сразу обнуляет `loadError`, поэтому
сообщение вместе с кнопкой (и её спиннером `:loading`) исчезает, а общий спиннер `page__loading` виден только при пустом списке.
Пока идёт повторный запрос, индикатора загрузки нет совсем. ТЗ, п. 4: «Покажите загрузку и блокируйте действие, пока его запрос
выполняется… дайте повторить действие». Alex попросил исправить.

## What Changes

- `useBookingSlots.load()` сбрасывает `loadError` только после успешного ответа, а не в начале запроса. Пока идёт повтор,
  сообщение остаётся на месте, кнопка «Повторить» показывает спиннер и неактивна (`:loading="loading"` уже есть).
- При новой ошибке сообщение обновляется текстом новой ошибки; при успехе исчезает.

Вне объёма: остальные элементы страницы, backend.
