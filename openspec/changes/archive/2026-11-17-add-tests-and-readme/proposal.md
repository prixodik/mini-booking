# Proposal

## Why

ТЗ п. 5: два обязательных теста и README, по которому проверяющий воспроизведёт запуск, поймёт гарантию уникальности и «какое время использует приложение».

## What Changes

- Два feature-теста PHPUnit: (1) успешная бронь свободного будущего слота, (2) повторный запрос на занятый слот → 409 и одна активная бронь.
- Тесты детерминированы: время фиксируется (`Carbon::setTestNow`), слоты создаются фабрикой/Seeder, БД — SQLite in-memory.
- Полный `README.md`: зависимости, окружение, команды запуска backend/frontend, миграции, Seeder, тесты, уникальность брони, время, ограничения.
- Дополнительные тесты (по возможности, не обязательны): прошедший слот, 422, отмена и повторная бронь, идемпотентность Seeder.

## Capabilities

### New Capabilities
- `backend-tests`: обязательные и опциональные автотесты backend.
- `project-readme`: содержание README.
