# Proposal

## Why

Alex: текущий интерфейс выглядит как стандартный шаблон из Bootstrap. Нужна аккуратная светлая тема, верстка по БЭМ и
готовое хорошее визуальное решение. ТЗ (п. 4) требует интерфейс, удобный на ноутбуке и телефоне; визуальное качество и
читаемость кода входят в оценку.

## What Changes

- Верстка по БЭМ: единые правила имён, один компонент = один блок, стили в `<style scoped>` рядом с компонентом,
  общие токены (цвета, отступы, радиусы, шрифты) в `assets/css/tokens.css`.
- Светлая тема: только светлая, контраст текста не ниже WCAG AA (4.5:1), статусы слотов различимы не только цветом.
- Визуальная основа — пресет PrimeVue 4, кастомизированный через `definePreset` (design tokens), без правки внутренних `.p-*` классов.
- Адаптивность: брейкпоинты 360 / 768 / 1280, сетка карточек слотов, касаемые зоны не меньше 44 px.
- Поведение страницы не меняется (см. capability `booking-ui` из `add-booking-frontend`).

Вне объёма (п. 1 ТЗ и решения Alex): тёмная тема, переключатель тем, i18n, новые страницы и функции, смена UI-библиотеки
(если Alex не выберет вариант C в `design.md`), анимации сверх стандартных переходов PrimeVue.

## Impact

`frontend/assets/css/tokens.css` (новый), `frontend/plugins/primevue.js` (пресет), `frontend/layouts/default.vue`,
`frontend/pages/index.vue`, `frontend/components/booking/*.vue` (только разметка классов и стили), `frontend/nuxt.config.js` (подключение CSS).
Зависит от `add-booking-frontend`; логика, API и composables не затрагиваются.
