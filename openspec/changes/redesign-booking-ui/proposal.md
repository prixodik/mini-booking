# Proposal

## Why

Alex: текущий интерфейс выглядит как стандартный шаблон из Bootstrap. Нужна аккуратная светлая тема, верстка по БЭМ и
готовое хорошее визуальное решение. ТЗ (п. 4) требует интерфейс, удобный на ноутбуке и телефоне; визуальное качество и
читаемость кода входят в оценку.

## What Changes

- Верстка по БЭМ: единые правила имён, один компонент = один блок, стили в `<style scoped>` рядом с компонентом,
  общие токены (цвета, отступы, радиусы, шрифты) в `assets/css/tokens.css`.
- Светлая тема: только светлая, контраст текста не ниже WCAG AA (4.5:1), статусы слотов различимы не только цветом.
- Визуальное направление (выбрано Alex): тема PrimeVue Aura (только светлая, акцент через `definePreset`) + оформление по ориентиру Sakai (карточки, шапка, отступы, типографика, тени). Шаблон Sakai целиком не копируется, Nuxt-проект и UI-библиотека не меняются. Внутренние `.p-*` классы не правятся.
- Адаптивность: брейкпоинты 360 / 768 / 1280, сетка карточек слотов, касаемые зоны не меньше 44 px.
- Поведение страницы не меняется (см. capability `booking-ui` из `add-booking-frontend`).

Вне объёма (п. 1 ТЗ и решения Alex): тёмная тема, переключатель тем, i18n, новые страницы и функции, смена UI-библиотеки и
перенос шаблона Sakai (боковое меню, дашборд, конфигуратор тем), анимации сверх стандартных переходов PrimeVue.

## Impact

`frontend/assets/css/tokens.css` (новый), `frontend/plugins/primevue.js` (пресет), `frontend/layouts/default.vue`,
`frontend/pages/index.vue`, `frontend/components/booking/*.vue` (только разметка классов и стили), `frontend/nuxt.config.js` (подключение CSS).
Зависит от `add-booking-frontend`; логика, API и composables не затрагиваются.

## Decisions of Alex

- Направление: Sakai как ориентир + Aura + БЭМ.
- `@primeuix/themes` закрепляется на MIT-версии 2.0.3 (по npm совместима по линии `@primeuix/styled` с `primevue` 4.5.5; запуск проверить при реализации).
- Акцент: фиолетовый; точный оттенок подобран по контрасту — `#6D28D9` (белый текст 7.10:1; на фоне страницы `#F1F5F9` — 6.49:1).
- Логотипа и иллюстрации в шапке нет; иконки календаря в шапке тоже нет.
- Шрифт: Alex просил Lato; в Lato нет кириллицы, поэтому выбран Nunito Sans (с кириллицей, локально, OFL-1.1); подтверждено Alex.
- Карточка слота: время слева сверху, статус справа сверху, кнопки внизу.
- Имя и email забронировавшего на карточках не показываем: ТЗ запрещает их в списке слотов.
- По умолчанию (пока без возражений): без stylelint (grep-проверки).
