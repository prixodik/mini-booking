# Spec Delta

## MODIFIED Requirements

### Requirement: Date filter
Страница SHALL один раз загружать расписание и фильтровать слоты по дате в браузере. Список дат MUST строиться из загруженных слотов в поясе расписания и MUST содержать только сегодняшнюю и будущие даты (в поясе расписания, по `meta.server_time`); прошедшие дни в фильтр MUST NOT попадать. По умолчанию выбирается сегодняшняя дата, а при её отсутствии — первая доступная. Над списком слотов SHALL выводиться выбранная дата полностью (день недели, число и месяц), например «Вторник, 17 ноября».

#### Scenario: Смена даты
- **WHEN** пользователь выбирает другую дату
- **THEN** список показывает 9 слотов выбранного дня без нового запроса к API, а над списком выводится полная выбранная дата

#### Scenario: Прошедшие дни не показываются
- **WHEN** в БД есть слоты вчерашнего дня (Seeder запускался в предыдущие дни)
- **THEN** вчерашней даты нет в фильтре, а сегодняшняя дата есть и её прошедшие слоты показаны со статусом «Прошёл»

#### Scenario: Повторный выбор той же даты
- **WHEN** пользователь нажимает уже выбранную дату
- **THEN** дата остаётся выбранной, список слотов не пропадает
