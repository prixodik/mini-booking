# Spec Delta

## MODIFIED Requirements

### Requirement: Loading and blocked actions
Пока запрос выполняется, страница SHALL показывать индикатор загрузки и блокировать связанное действие (кнопки отправки, отмены и обновления), чтобы исключить повторную отправку. Индикатор MUST быть виден на элементе, который запустил действие: на кнопке отправки в диалоге брони и на кнопке «Отменить бронь» того слота, бронь которого отменяется.

#### Scenario: Двойной клик
- **WHEN** пользователь дважды быстро нажимает «Забронировать»
- **THEN** отправляется один запрос, кнопка отключена до ответа

#### Scenario: Индикатор при отмене
- **WHEN** пользователь подтверждает отмену брони слота, а ответ сервера ещё не пришёл
- **THEN** на кнопке «Отменить бронь» этого слота виден спиннер, остальные кнопки действий отключены; после ответа спиннер пропадает
