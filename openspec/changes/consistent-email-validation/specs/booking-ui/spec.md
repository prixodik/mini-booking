# Spec Delta

## ADDED Requirements

### Requirement: Email check consistent with the server
Браузер SHALL проверять формат email тем же правилом, которое сервер добавляет к проверке Laravel (`^[^\s@]+@[^\s@]+\.[^\s@]+$`), чтобы любой адрес, принятый сервером, принимался и формой. Если сервер всё же отклонил адрес (422), ошибка MUST показываться под полем «Email», значения формы сохраняются.

#### Scenario: Адрес без точки в домене
- **WHEN** пользователь вводит `a@b` и отправляет форму
- **THEN** запрос не отправляется, под полем «Email» видно «Укажите корректный email.»

#### Scenario: Адрес, отклонённый только сервером
- **WHEN** пользователь вводит `a@b..c` (браузер пропускает) и отправляет форму
- **THEN** сервер отвечает 422, под полем «Email» видна ошибка сервера, форма открыта
