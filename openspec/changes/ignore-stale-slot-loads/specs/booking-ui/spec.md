# Spec Delta

## ADDED Requirements

### Requirement: Latest slot list wins
Если запросы `GET /api/slots` перекрываются по времени, страница MUST применять только ответ на последний запущенный запрос: его данные, его ошибку и снятие индикатора загрузки. Ответы и ошибки более ранних запросов MUST NOT менять список, сообщение об ошибке и индикатор загрузки.

#### Scenario: Старый ответ пришёл позже нового
- **WHEN** запущена загрузка A, затем загрузка B, и ответ B пришёл раньше ответа A
- **THEN** на странице остаются данные B; ответ A не меняет список

#### Scenario: Ошибка устаревшего запроса
- **WHEN** загрузка A завершилась ошибкой уже после успешного ответа более поздней загрузки B
- **THEN** сообщения об ошибке загрузки нет, видны данные B
