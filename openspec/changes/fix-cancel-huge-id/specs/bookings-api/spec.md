# Spec Delta

## MODIFIED Requirements

### Requirement: Cancel booking
`DELETE /api/bookings/{id}` SHALL отменять бронь, возвращая 204 без тела. Для неизвестного ID API MUST вернуть 404 с JSON `{"message": "Бронь не найдена"}`; это относится и к ID из цифр, который не помещается в целое число сервера, — такой запрос MUST NOT приводить к ответу 500. Повторная отмена уже отменённой брони SHALL возвращать 404 с JSON `{"message": "Бронь уже отменена"}`, чтобы клиент мог отличить повторную отмену от неизвестного ID. Авторизация не требуется.

#### Scenario: Успешная отмена
- **WHEN** отменяется активная бронь будущего слота
- **THEN** ответ 204, а слот в `GET /api/slots` снова имеет `status = available`

#### Scenario: Повторная отмена
- **WHEN** DELETE вызывается второй раз для той же брони
- **THEN** ответ 404 с сообщением «Бронь уже отменена», данные не меняются, `cancelled_at` остаётся прежним

#### Scenario: Неизвестный ID
- **WHEN** DELETE вызывается для несуществующего ID
- **THEN** ответ 404 с сообщением «Бронь не найдена»

#### Scenario: Слишком большой ID
- **WHEN** DELETE вызывается для `/api/bookings/99999999999999999999` (больше максимального целого)
- **THEN** ответ 404 с JSON `{"message": "Бронь не найдена."}`, а не 500
